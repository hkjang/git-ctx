# git-ctx v0.52.5

이번 릴리스는 락파일 색인의 **자원 사용**을 바로잡습니다. 기본 서비스 포트는 계속 `4747`이며 기존 API·MCP 호환성을 유지합니다.

## 수정

- **매니페스트·락파일 내용을 메모리에 모아 두던 문제.** 한 ref의 모든 매니페스트와 락파일 원문을 맵에 담아 두었다가 마지막에 한 번에 파싱했습니다. 락파일은 본래 크고(상한 8MB) 모노레포에는 수십 개가 있어, 색인 한 번이 수백 MB를 붙들 수 있었습니다. 이제 **읽는 즉시 파싱하고 원문은 버립니다.**
- **선언 1건마다 INSERT 하던 문제.** go.sum 하나만으로도 수천 번의 왕복이 발생했습니다. 200행 단위 배치로 묶습니다.
- ref 단위 인벤토리 총량 상한(20,000건)을 추가하고, 상한에 걸리면 색인 작업 경고에 남깁니다. 인벤토리는 조직이 무엇을 쓰는지에 대한 카탈로그이지 락파일 사본이 아니기 때문입니다. 락파일 1건당 상한(4,000건)은 그대로입니다.

## 업그레이드 참고

- 마이그레이션이나 재색인은 필요하지 않습니다. 다음 색인부터 새 경로가 적용됩니다.
- 이미 20,000건을 넘긴 ref가 있다면 재색인 시 상한까지만 유지되고 그 사실이 작업 경고로 표시됩니다.

## 오프라인 Docker 이미지

릴리스 자산은 아키텍처 접미사가 없는 다음 두 파일입니다.

- `git-ctx-v0.52.5.tar.gz`
- `git-ctx-v0.52.5.tar.gz.sha256`

```bash
sha256sum -c git-ctx-v0.52.5.tar.gz.sha256
gzip -dc git-ctx-v0.52.5.tar.gz | docker load
docker image inspect git-ctx:v0.52.5 --format '{{.Os}}/{{.Architecture}} {{.Config.User}}'
```

기대 결과는 `linux/amd64 10001`입니다. 아카이브에는 `git-ctx:v0.52.5`와 `git-ctx:0.52.5` 태그가 포함됩니다.
