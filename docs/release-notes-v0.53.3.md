# git-ctx v0.53.3

이번 릴리스는 인증 경로의 **요청당 데이터베이스 쓰기**를 없앱니다. 기본 서비스 포트는 계속 `4747`이며 기존 API·MCP 호환성을 유지합니다.

## 개선

- API 키 인증이 요청마다 `last_used_at` 을 갱신하고 있었습니다. SQLite 는 쓰기가 단일 라이터에 직렬화되므로, 에이전트 하나가 도구를 연속 호출하면 **타임스탬프 하나 때문에 자기 자신 뒤에 줄을 서는** 구조였습니다.
- 이제 키당 1분에 한 번만 기록합니다. 운영 화면은 이 값을 날짜로 읽으므로 정밀도 손실이 없고, 복제본이 여러 개여도 값이 뒤로 가지 않도록 SQL 조건을 함께 둡니다.
- 호출량 제한이 설정된 키는 기존대로 매 호출을 집계합니다. 제한이 없으면 그 쓰기도 발생하지 않습니다.

## 감사 결과 (수정 없음)

- API 키 인증 경로를 감사했습니다. 해시 비교는 상수 시간이고, 만료·중지·폐기 상태와 CIDR 제한, 호출량 제한이 모두 인증 시점에 적용되며, 사용자가 비활성화되면 그 사용자의 키도 즉시 거부됩니다. 변경할 결함은 없었습니다.

## 업그레이드 참고

- 마이그레이션이나 재색인은 필요하지 않습니다.
- `last_used_at` 은 최대 1분 늦게 반영됩니다. 키 사용 여부 판단에는 영향이 없습니다.

## 오프라인 Docker 이미지

릴리스 자산은 아키텍처 접미사가 없는 다음 두 파일입니다.

- `git-ctx-v0.53.3.tar.gz`
- `git-ctx-v0.53.3.tar.gz.sha256`

```bash
sha256sum -c git-ctx-v0.53.3.tar.gz.sha256
gzip -dc git-ctx-v0.53.3.tar.gz | docker load
docker image inspect git-ctx:v0.53.3 --format '{{.Os}}/{{.Architecture}} {{.Config.User}}'
```

기대 결과는 `linux/amd64 10001`입니다. 아카이브에는 `git-ctx:v0.53.3`과 `git-ctx:0.53.3` 태그가 포함됩니다.
