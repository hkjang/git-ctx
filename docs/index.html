KEY FEATURES

엔터프라이즈 AI 코딩을 위한 핵심 기능

git-ctx는 외부 유출 없는 온프레미스 환경에서 AI 모델에 가장 정확하고 안전한 지식을 제공합니다.

완벽한 보안 및 ACL 권한 검증

Keycloak OIDC 및 Bitbucket/GitLab ACL을 검색 후보 생성 선단계에서 100% 검증합니다. 권한 없는 소스코드와 문서는 노출되지 않습니다.

Context7 호환 2단계 MCP 흐름

resolve-library-id → query-docs/search-code 구조로 에이전트의 토큰 소모를 극대화로 줄이고 정교한 컨텍스트 조각만 주입합니다.

AST 코드 구조 & 심볼 그래프

Go, Java, TypeScript, Python, SQL 구조 파싱 기반으로 find-symbol, trace-dependencies, find-dependents 심볼 영향도 분석을 지원합니다.

하이브리드 BM25 + 임베딩 검색

PostgreSQL tsvector 키워드 검색과 사내 OpenAI 호환 벡터 검색을 결합합니다. 모델 장애 시 safe-lexical 자동 폴백이 작동합니다.

X-Ray 감사 및 검색 설명서

MCP 호출 감사 로그, 단계별 수용/탈락 근거(Diagnostics), latency 및 explain-search-result로 투명한 운영 상태를 파악하세요.

폐쇄망(Air-gapped) 원클릭 배포

인터넷 연결이 차단된 환경에서도 오프라인 이미지 패키징, K8s Kustomize, Docker Compose, SQLite/PostgreSQL 이중 복구 모드를 제공합니다.

MCP TOOL ECOSYSTEM

AI 에이전트와 소통하는 MCP 도구 모음

Cursor, Claude Desktop, Antigravity 등 최신 AI 개발 도구에서 바로 사용할 수 있는 풍부한 도구를 제공합니다.

search-code Core Retrieval Tool

Library ID 지정 없이 사용자 접근 권한(ACL) 범위 내 모든 사내 저장소에서 키워드/원격 Code Search API 및 벡터 검색을 결합하여 코드를 정교하게 탐색합니다.

JSON-RPC Request Example 
{
  "jsonrpc": "2.0",
  "method": "tools/call",
  "params": {
    "name": "search-code",
    "arguments": {
      "query": "Keycloak OIDC JWT token validation",
      "limit": 5
    }
  },
  "id": 1
}
resolve-library-id Context7 Standard Tool

에이전트가 탐색하려는 프로젝트나 저장소 이름을 정규화된 Library ID(예: project/repo/main)로 매핑하고 사용 권한을 확인합니다.

JSON-RPC Request Example 
{
  "jsonrpc": "2.0",
  "method": "tools/call",
  "params": {
    "name": "resolve-library-id",
    "arguments": {
      "libraryName": "git-ctx",
      "query": "authentication adapter"
    }
  },
  "id": 2
}
find-symbol AST Code Parser

Go AST, Java, TypeScript, Python, SQL 파싱 결과에서 특정 클래스, 인터페이스, 메서드, 구조체 정의와 주석 문맥을 즉시 추출합니다.

JSON-RPC Request Example 
{
  "jsonrpc": "2.0",
  "method": "tools/call",
  "params": {
    "name": "find-symbol",
    "arguments": {
      "symbol": "BitbucketAdapter",
      "language": "go"
    }
  },
  "id": 3
}
compare-refs Impact Analysis Tool

두 브랜치/태그 간의 변경 사항을 심볼 수준에서 비교하고, 해당 변경이 저장소 내 타 코드에 미치는 연관 영향도를 산출합니다.

JSON-RPC Request Example 
{
  "jsonrpc": "2.0",
  "method": "tools/call",
  "params": {
    "name": "compare-refs",
    "arguments": {
      "libraryId": "hkjang/git-ctx",
      "baseRef": "main",
      "targetRef": "feature/oidc-pkce"
    }
  },
  "id": 4
}
get-repository-map Repository Insights

저장소의 사용 언어 비율, 핵심 진입점(Entrypoint), 주요 패키지 구조 및 설정 파일 규약을 요약된 MAP 객체로 반환합니다.

JSON-RPC Request Example 
{
  "jsonrpc": "2.0",
  "method": "tools/call",
  "params": {
    "name": "get-repository-map",
    "arguments": {
      "libraryId": "hkjang/git-ctx"
    }
  },
  "id": 5
}
trace-dependencies Graph Analytics

특정 파일이나 모듈의 import, 호출 관계, 데이터베이스 테이블 연관도를 트레이싱하여 코드 전파 그래프를 시각화 가능한 데이터로 구성합니다.

JSON-RPC Request Example 
{
  "jsonrpc": "2.0",
  "method": "tools/call",
  "params": {
    "name": "trace-dependencies",
    "arguments": {
      "libraryId": "hkjang/git-ctx",
      "filePath": "internal/mcp/server.go"
    }
  },
  "id": 6
}

몇 분 만에 구축하는 git-ctx

단 두 개의 환경 변수 설정으로 바로 온프레미스 서버를 기동하고 MCP 클라이언트를 연결할 수 있습니다.

1

1. git-ctx 서비스 기동 (Docker 또는 Go 실행)

장기 복구 키(GIT_CTX_RECOVERY_KEY)와 DB 접속 DSN을 지정하여 서버를 기동합니다.

Bash 
export GIT_CTX_RECOVERY_KEY="$(openssl rand -base64 48)"
export GIT_CTX_DB_DSN='file:git-ctx.db?_foreign_keys=on&_busy_timeout=5000'

# Go 바이너리 실행 또는 Docker 컨테이너 실행
go run ./cmd/git-ctx
2

2. 최초 관리자 복구 토큰 확인 & SSO 설정

최초 기동 시 생성되는 backups/bootstrap-admin.token으로 관리 콘솔 로그인 후 Keycloak OIDC를 연결합니다.

Curl API Test 
curl -H "Authorization: Bearer $(cat backups/bootstrap-admin.token)" \
  http://localhost:4747/api/v1/admin/settings
3

3. MCP 클라이언트 설정 (예: claude_desktop_config.json)

발급받은 MCP API Key를 사용하여 에이전트에 git-ctx MCP 서버를 등록합니다.

MCP Config JSON 
{
  "mcpServers": {
    "git-ctx": {
      "url": "http://localhost:4747/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_API_KEY"
      }
    }
  }
}
FAQ & AEO

자주 묻는 질문 (FAQ)

git-ctx 도입 및 운영에 관한 주요 궁금증을 확인하세요.

git-ctx는 사내 Bitbucket Server 6.9.1과 GitLab의 소스코드 및 개발 문서를 색인하여 Context7 호환 MCP(Model Context Protocol)로 AI 에이전트에 제공하는 온프레미스 지식 플랫폼입니다. 사내 코드가 외부로 유출되지 않으면서도 개발자 AI 에이전트가 사내 전체 코드베이스와 문서 문맥을 실시간 활용할 수 있게 합니다.

전체 저장소를 통째로 토큰에 넣는 대신 1단계 resolve-library-id로 대상 저장소/버전을 탐색하고 2단계 query-docs / search-code로 필요한 코드 청크와 문맥만 정확히 검색합니다. 이를 통해 LLM 프롬프트 비용을 최대 90% 절감하고 첫 호출 정확도를 극대화합니다.

git-ctx는 Keycloak OIDC 사용자의 계정 및 그룹 속성을 Bitbucket/GitLab ACL 권한과 동기화합니다. 검색 후보 생성 이전(Pre-filtering) 단계에서 사용자 권한을 검사하므로, 사용자가 소스 관리 시스템에서 접근 권한이 없는 저장소나 소스코드는 검색 결과 및 AI 토큰에 100% 노출되지 않습니다.

네, 완전히 지원합니다. git-ctx는 외부 Context7 서버나 인터넷 서비스에 전혀 의존하지 않으며, 오프라인 컨테이너 이미지 패키징, PostgreSQL / SQLite 지원, Kubernetes Kustomize 매니페스트 및 사내 로컬 LLM/임베딩 모델 호환 인터페이스를 제공합니다.

Model Context Protocol(MCP) 표준을 준수하는 모든 클라이언트와 연동됩니다. Cursor, Antigravity CLI/IDE, Claude Desktop, VS Code (Continue/MCP extensions) 등 다양한 에이전트 환경에서 지원됩니다.

지금 git-ctx로 사내 AI 개발 환경을 혁신하세요

보안 유출 걱정 없는 온프레미스 MCP 지식 플랫폼 git-ctx를 저장소에서 확인해 보세요.
