# git-ctx v0.57.1

이번 릴리스는 **재순위(리랭커)가 무엇을 했는지 답에 밝힙니다.** 기본 서비스 포트는 계속 `4747`이며 기존 API·MCP 호환성을 유지합니다.

## 수정

- **재순위 모델이 조용히 실패하고 있었습니다.** 호출이 실패하면 검색 점수 순서를 그대로 쓰고 아무 말도 하지 않았습니다. 읽는 쪽은 재순위된 결과를 보고 있다고 믿을 수밖에 없었고, 답에도 진단에도 상태 화면에도 그 사실이 없었습니다. **답의 순서는 답의 일부입니다.**
- 이제 세 경우를 구분해 말합니다 — 재순위로 정렬했는지, 모델을 호출하지 못해 그대로 두었는지(이유 포함), 모델이 문서 수와 다른 개수의 점수를 돌려줘 순서를 바꾸지 않았는지. 마지막 경우는 그대로 믿었다면 순서가 조용히 어긋났을 자리입니다.
- `get-platform-status` 가 재순위 설정 상태를 함께 보고합니다 — 꺼짐, 켜짐(모델명), 또는 켜져 있으나 설정으로는 쓸 수 없음.

## 실증

- 결정적 점수를 돌려주는 리랭커 서버를 세워 `query-docs` 가 실제로 재순위를 호출하는 것을 확인(질의당 임베딩 1회·재순위 1회)
- 리랭커만 중단시킨 뒤: 답은 그대로 나오고 4ms 안에 끝나며, 첫 줄에 호출 실패와 이유가 표시됨
- 상태 화면에 `Reranker: enabled (fake-rerank)` 표시 확인

## 검증

- 실패·성공·점수 개수 불일치 세 경우의 문구 시험
- FTS5 빌드·태그 없는 빌드 양쪽 전체 단위·통합·race 테스트

## 업그레이드 참고

- 마이그레이션이나 재색인은 필요하지 않습니다.
- 재순위를 쓰는 설치는 답 상단에 한 줄이 추가됩니다. 재순위가 성공하면 그 사실도 표시됩니다.
