# git-ctx v0.58.6

이번 릴리스는 **릴리스 절차 자체의 결함**을 고칩니다. 기본 서비스 포트는 계속 `4747`이며 기존 API·MCP 호환성을 유지합니다.

## 수정

- 버전 정합성 검사가 완료 감사 블록의 **모든 버전 문자열**이 이번 릴리스 버전과 같기를 요구했습니다. 그래서 “구버전에서 업그레이드해 확인했다” 같은 **사실을 적으면 릴리스가 깨졌습니다.** 실제로 이 함정에 두 번 걸렸고, 두 번 모두 검사 실패로 명령 연결이 끊긴 채 태그만 올라가 이미 공개된 태그를 지워야 했습니다.
- 이제 감사 블록에서 **산출물 줄(Kustomize·Docker)** 의 버전만 검사합니다. 그 줄은 이 릴리스가 만드는 이미지를 가리키므로 어긋나면 잘못된 것이고, 나머지 서술은 사실을 적는 자리입니다.

## 추가

- `scripts/release.sh` — 검증 → 시험 → 커밋 → **커밋 확인** → 푸시 → 태그를 이 순서로만 수행합니다.
  - 태그가 이미 있으면(로컬·원격 어느 쪽이든) 중단합니다. 공개된 태그는 덮어쓰지 않습니다.
  - 릴리스 노트 파일이 없으면 중단합니다.
  - **커밋이 릴리스 노트와 해당 버전을 담고 있는지 확인한 뒤에만 태그를 만듭니다.** 두 번의 사고가 정확히 이 불변식을 깬 것이었습니다.
  - `--dry-run` 으로 무엇이 커밋될지 먼저 볼 수 있습니다.

## 검증

- 감사 블록에 옛 버전을 언급하는 문장을 넣어도 통과하고, 산출물 줄의 버전이 어긋나면 실패하는 것을 시험으로 고정
- 릴리스 도구 시험(`test/release/version-sync.test.sh`) 통과
- FTS5 빌드·태그 없는 빌드 양쪽 전체 단위·통합·race 테스트

## 업그레이드 참고

- 제품 동작 변경은 없습니다. 마이그레이션이나 재색인도 필요하지 않습니다.
