# git-ctx v0.58.7

이번 릴리스는 **콘솔을 실제 브라우저에서 열어 보는 시험**을 추가합니다. 기본 서비스 포트는 계속 `4747`이며 기존 API·MCP 호환성을 유지합니다.

## 배경

기존 콘솔 시험은 `web/app.js` 와 `web/index.html` 을 **텍스트로 읽습니다.** 화면이 비어 렌더링되는 것은 볼 수 없고, 실제로 그렇게 배포된 적이 있습니다 — 콘솔이 호출하던 두 엔드포인트가 라우팅되지 않아 카드 두 개가 계속 비어 있었고(v0.53.4 에서 수정), 어떤 시험도 알아채지 못했습니다.

## 추가

- `test/web/render-sweep.js` — 빌드된 서버를 띄우고 headless 브라우저로 콘솔에 로그인한 뒤, **관리자 메뉴의 모든 항목을 실제로 클릭**합니다. 화면이 비어 있거나 JavaScript 오류가 나면 실패합니다.
  - 의존성이 없습니다. Node 22 의 내장 WebSocket 으로 DevTools 프로토콜을 직접 씁니다.
  - 바이너리나 브라우저가 없으면 건너뛰므로, 개발자 기계의 기존 `node test/web/*.test.js` 실행은 그대로입니다.
- CI 의 콘솔 작업에 이 스윕을 넣었습니다.

## 실증

실제 인스턴스에서 관리자 화면 11종을 확인했습니다. **수정할 결함은 없었습니다.**

```text

감사 · 데이터베이스 · 운영 상태 · 백업·복구      모두 렌더링, JS 오류 0건
v0.53.4 에서 고친 두 카드                        웹훅 수신·의존성 인벤토리 모두 실데이터 표시
```

- 화면 하나를 비운 빌드로 스윕을 돌려 실패하는 것을 확인했습니다.
