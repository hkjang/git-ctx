# git-ctx v0.52.1

이번 릴리스는 v0.52.0의 의존성 인벤토리에 **보안 공지 판정**을 더한 릴리스입니다. 기본 서비스 포트는 계속 `4747`이며 기존 API·MCP 호환성을 유지합니다.

## 주요 개선

- `find-dependency-usage`에 수정 버전 인자 `fixedIn`을 추가했습니다. 각 버전 묶음을 **영향 / 안전 / 판정 불가**로 분류하고, 저장소 수 기준으로 영향 범위를 집계합니다. 콘솔의 Dependency Usage 카드에도 같은 입력과 표시를 추가했습니다.
- **범위·부동 버전은 안전으로 접지 않습니다.** `^1.2.0`, `latest`, `1.2.x`, git 참조처럼 매니페스트만으로 결정할 수 없는 선언은 판정 불가로 남기고, 락파일·빌드 산출물로 확인하라고 안내합니다. 잘못된 안심이 보안 공지 대응에서 가장 비싼 실수입니다.
- 범위 선언의 **하한은 판정에 사용합니다.** `>=2.17.1`은 수정 버전 이상으로 고정되어 있으므로 영향 없음으로 판단합니다.
- 한 저장소가 영향 버전과 수정 버전을 **함께 선언**하면 영향으로 분류합니다. 더 엄격한 쪽이 이기므로 일부만 고친 저장소가 완료로 보고되지 않습니다.
- 버전 묶음은 **영향 → 판정 불가 → 안전** 순으로 정렬해, 공지 대응에서 위에서부터 읽으면 되도록 했습니다.
- 사전 릴리스(`1.0.0-rc.1`)는 해당 정식 릴리스보다 낮게 비교합니다.

## 업그레이드 참고

- 마이그레이션이나 재색인은 필요하지 않습니다. v0.52.0에서 만든 인벤토리를 그대로 사용합니다.
- `fixedIn`을 넘기지 않으면 v0.52.0과 동일한 인벤토리 응답을 반환합니다.
- 기존 API 키 Scope는 변경되지 않습니다.

## 오프라인 Docker 이미지

릴리스 자산은 아키텍처 접미사가 없는 다음 두 파일입니다.

- `git-ctx-v0.52.1.tar.gz`
- `git-ctx-v0.52.1.tar.gz.sha256`

```bash
sha256sum -c git-ctx-v0.52.1.tar.gz.sha256
gzip -dc git-ctx-v0.52.1.tar.gz | docker load
docker image inspect git-ctx:v0.52.1 --format '{{.Os}}/{{.Architecture}} {{.Config.User}}'
```

기대 결과는 `linux/amd64 10001`입니다. 아카이브에는 `git-ctx:v0.52.1`과 `git-ctx:0.52.1` 태그가 포함됩니다.

- 버전 비교 회귀 시험: 비교 가능한 형태 9종과 판정 불가 형태 10종, 사전 릴리스 순서, 범위 하한
