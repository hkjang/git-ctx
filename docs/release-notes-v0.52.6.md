# git-ctx v0.52.6

이번 릴리스는 **API 키 저장소 제한 우회 결함**을 고치고, 같은 종류의 누락이 다시 생기지 않도록 회귀 가드를 추가합니다. 기본 서비스 포트는 계속 `4747`이며 기존 API·MCP 호환성을 유지합니다.

## 보안 수정

- **`get-context-pack` 이 API 키의 저장소 허용 목록을 확인하지 않았습니다.** Context Pack 은 여러 저장소를 묶는 도구이므로, 저장소가 제한된 키로 팩을 호출하면 사용자 ACL 로 읽을 수 있는 **팩 안의 다른 저장소 내용까지** 반환됐습니다. 나머지 31개 도구는 모두 제한을 지키고 있었고, 이 도구만 빠져 있었습니다.
  - 이제 팩 구성원을 수집 단계 **이전에** 걸러, 허용되지 않은 저장소에는 질의 자체를 보내지 않습니다.
  - 사용자 ACL 로만 제한되는 기존 호출(콘솔의 관리자 세션 등)은 동작이 바뀌지 않습니다.

**영향 범위**: 저장소 제한(`restrictions.repositories`)이 설정된 MCP API 키로 `get-context-pack` 을 호출한 경우에만 해당합니다. 제한이 없는 키와 로그인 세션은 영향이 없습니다. 감사 로그의 `mcp_calls` 에서 `tool='get-context-pack'` 이고 API 키가 사용된 호출로 조회 이력을 확인할 수 있습니다.

## 개선

- **도구별 허용 목록 회귀 가드**를 추가했습니다. 표식이 든 저장소를 만들어 두고 비관리 도구 **전부**를 제한된 키로 호출해 표식이 응답에 나오면 실패합니다. 표에 없는 도구가 레지스트리에 추가되면 그것만으로도 실패하므로, 새 도구는 이 검사를 통과하도록 강제됩니다.

## 업그레이드 참고

- 마이그레이션이나 재색인은 필요하지 않습니다.
- 저장소 제한 키를 쓰는 조직은 이 릴리스로 올리는 것을 권장합니다.

## 오프라인 Docker 이미지

릴리스 자산은 아키텍처 접미사가 없는 다음 두 파일입니다.

- `git-ctx-v0.52.6.tar.gz`
- `git-ctx-v0.52.6.tar.gz.sha256`

```bash
sha256sum -c git-ctx-v0.52.6.tar.gz.sha256
gzip -dc git-ctx-v0.52.6.tar.gz | docker load
docker image inspect git-ctx:v0.52.6 --format '{{.Os}}/{{.Architecture}} {{.Config.User}}'
```

기대 결과는 `linux/amd64 10001`입니다. 아카이브에는 `git-ctx:v0.52.6`과 `git-ctx:0.52.6` 태그가 포함됩니다.

## 검증

- Go 전체 단위·통합·race 테스트, vet와 build
- Context Pack 제한 회귀 시험: 제한 키는 허용 저장소 내용만 받고, 제한 없는 호출은 그대로 동작
- 전 도구 허용 목록 누출 가드: 비관리 도구 29종을 제한 키로 호출해 표식 미노출 확인, 수정 코드를 되돌리면 가드가 실패하는 것까지 역검증
- 관리자·사용자 UI JavaScript 구문 및 계약 시험
