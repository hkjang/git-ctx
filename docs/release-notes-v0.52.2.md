# git-ctx v0.52.2

이번 릴리스는 의존성 인벤토리에 **카탈로그 전체 가시성**을 더한 릴리스입니다. 기본 서비스 포트는 계속 `4747`이며 기존 API·MCP 호환성을 유지합니다.

## 주요 개선

- `GET /api/v1/admin/dependency-inventory` 와 소스·색인 화면의 **의존성 인벤토리** 카드를 추가했습니다. 패키지 이름을 미리 알아야 답이 나오던 `find-dependency-usage` 와 달리, 목록 자체에서 시작해 "이 조직이 무엇에 의존하는가"를 묻습니다.
- 정렬 기준은 **버전 분산**입니다. 한 버전으로 널리 쓰는 라이브러리는 결정할 것이 없고, 저장소마다 버전이 갈린 라이브러리가 표준화 대상이므로 그쪽을 위로 올립니다. 분산된 패키지 수를 별도로 집계합니다.
- **매니페스트가 색인된 저장소 비율을 항상 함께 표시합니다.** 일부만 색인된 상태의 짧은 목록을 "우리는 별로 안 쓴다"로 읽으면 표준화 판단이 통째로 틀리기 때문입니다. 커버리지가 100%가 아니면 화면과 응답 진단에서 명시합니다.
- 생태계별 패키지 종수 요약과 생태계 필터를 제공합니다.
- 집계는 호출자의 ACL 범위 안에서만 이루어집니다. 읽을 수 없는 저장소는 커버리지 분모에도, 패키지 집계에도 포함되지 않습니다.

## 업그레이드 참고

- 마이그레이션이나 재색인은 필요하지 않습니다. v0.52.0 이후 만들어진 인벤토리를 그대로 집계합니다.
- 인벤토리가 비어 있으면 화면이 재색인을 안내합니다.
- 새 엔드포인트는 `source-admin`, `search-admin`, `readonly-operator` 역할에 열려 있습니다.

## 오프라인 Docker 이미지

릴리스 자산은 아키텍처 접미사가 없는 다음 두 파일입니다.

- `git-ctx-v0.52.2.tar.gz`
- `git-ctx-v0.52.2.tar.gz.sha256`

```bash
sha256sum -c git-ctx-v0.52.2.tar.gz.sha256
gzip -dc git-ctx-v0.52.2.tar.gz | docker load
docker image inspect git-ctx:v0.52.2 --format '{{.Os}}/{{.Architecture}} {{.Config.User}}'
```

기대 결과는 `linux/amd64 10001`입니다. 아카이브에는 `git-ctx:v0.52.2`와 `git-ctx:0.52.2` 태그가 포함됩니다.
