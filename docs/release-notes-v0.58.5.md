# git-ctx v0.58.5

이번 릴리스는 **구버전 데이터베이스 업그레이드**를 실측하고 그 경로를 시험으로 남깁니다. 기본 서비스 포트는 계속 `4747`이며 기존 API·MCP 호환성을 유지합니다.

## 실증 (v0.50.0 → 현행)

모든 온프레미스 설치가 언젠가 하는 일 — 구버전 바이너리를 멈추고 신버전을 같은 데이터베이스에 올리는 것 — 을 실제로 해봤습니다. **수정할 결함은 없었습니다.**

```text
v0.50.0 로 기동   마이그레이션 42개, 저장소·권한·청크 5건 적재
현행으로 교체     마이그레이션 46개까지 자동 적용, 오류 없음
데이터            청크 5건 그대로, policy_revision 열 추가됨
전문 인덱스       v0.50.0 에는 없던 인덱스가 만들어지고 기존 청크 5건이 채워짐
검색              업그레이드 전에 색인된 내용이 새 인덱스로 검색됨
상태              플랫폼 상태가 새 항목(전문 인덱스·알림)을 보고함
```

## 추가

- `TestUpgradingAnOlderDatabaseKeepsItSearchable` — 구버전 스키마 상태를 되돌린 데이터베이스를 만들고 현행 코드로 열어, 마이그레이션 적용·데이터 보존·**인덱스 backfill** 을 확인합니다.
- backfill 을 꺼 보고 “5건 중 0건만 검색 가능” 으로 실패하는 것을 확인했습니다. 이 backfill 이 없으면 업그레이드가 **조용히 검색 불가능한 상태**를 만듭니다.

## 검증

- FTS5 빌드·태그 없는 빌드 양쪽 전체 단위·통합·race 테스트
- v0.50.0 바이너리를 빌드해 실제 업그레이드 수행

## 업그레이드 참고

- 제품 동작 변경은 없습니다. 마이그레이션이나 재색인도 필요하지 않습니다.
- 큰 데이터베이스는 첫 기동 때 전문 인덱스를 한 번 채우므로 그만큼 시간이 걸립니다.
