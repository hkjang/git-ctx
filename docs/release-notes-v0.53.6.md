# git-ctx v0.53.6

이번 릴리스는 MCP 호출 감사에서 **보이지 않던 두 가지**를 고칩니다. 기본 서비스 포트는 계속 `4747`이며 기존 API·MCP 호환성을 유지합니다.

## 수정

- **권한 밖 도구 호출이 감사에 전혀 남지 않았습니다.** 자격증명이 부여받지 않은 도구를 호출하면 거절 메시지만 돌려주고 기록 없이 끝났습니다. 보안 검토가 가장 먼저 찾는 신호가 빠져 있던 셈입니다. 이제 다른 호출과 동일하게 기록하며, `tool_not_permitted` 오류 코드로 일반 실패와 구분됩니다.
- **감사에 적히는 클라이언트 주소에 임시 포트가 붙어 있었습니다.** `[::1]:35910` 같은 값은 CIDR 제한과 대조할 수 없고 화면에서 걸러낼 수도 없습니다. 또 MCP 계층이 `X-Forwarded-For` 를 무조건 신뢰해, 프록시 뒤가 아닌 호출자가 자기 주소를 감사 기록에 써 넣을 수 있었습니다.
- 이제 HTTP 계층이 신뢰 프록시 정책을 적용해 한 번 확정한 주소를 요청 컨텍스트로 전달하고, 이후 모든 기록이 같은 값을 씁니다. API 키의 CIDR 제한을 판정한 주소와 감사에 남는 주소가 항상 일치합니다.

## 업그레이드 참고

- 마이그레이션이나 재색인은 필요하지 않습니다.
- 기존 감사 행의 주소 형식은 그대로 남습니다. 새 호출부터 포트 없는 주소로 기록됩니다.
- 권한 밖 호출이 기록되기 시작하므로, MCP 오류 통계에 `tool_not_permitted` 항목이 새로 나타날 수 있습니다.

## 검증

- 실제 인스턴스에서 scope 밖 `read-file` 호출 후 감사 행 확인: `tool_not_permitted`, 주소 `::1`, 키 prefix 일치
- 거절 기록·주소 확정 회귀 시험(기록 경로를 되돌려 실패하는 것까지 확인)
- Go 전체 단위·통합·race 테스트, vet와 build
