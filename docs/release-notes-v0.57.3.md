# git-ctx v0.57.3

이번 릴리스는 **도달하지 못한 알림을 플랫폼 상태에 드러냅니다.** 기본 서비스 포트는 계속 `4747`이며 기존 API·MCP 호환성을 유지합니다.

## 개선

- 알림이 끝내 전달되지 못하면(재시도 소진) 관리자 화면의 목록에만 남고, 그 사실을 알려주는 통로가 없었습니다. **알려줄 수단 자체가 고장 난 상황**이므로 운영자가 가장 늦게 알아차리는 실패입니다.
- `get-platform-status` 가 이제 발송 상태를 함께 보고합니다 — 실패 없음, 재시도 중 N건, 또는 재시도를 소진한 N건과 그때 해야 할 일. 에이전트에게 플랫폼 상태를 물으면 이 사실이 함께 나옵니다.

## 실증 (알림 발송 수명주기)

가짜 수신기를 세워 실제 인스턴스에서 전 과정을 확인했습니다. **수정할 결함은 없었습니다.**

```text
발송        알림 생성 → 발송 행 생성 → Authorization 헤더와 함께 POST → delivered
실패        수신기가 503 → failed, 시도 1, 사유 기록
재시도      지수 백오프(1·2·4분)로 재시도, 시도 2 → 3
데드레터    maxAttempts(3) 도달 시 dead, 더 이상 시도하지 않음
관리자 재시도  dead 행을 재시도 → delivered (시도 4)
```

- 목적지가 바뀐 이전 발송 행은 `superseded` 로 남고 새 목적지로 중복 발송되지 않는 설계도 코드로 확인했습니다.

## 검증

- 정상·재시도 중·소진 세 상태의 상태 문구 시험
- FTS5 빌드·태그 없는 빌드 양쪽 전체 단위·통합·race 테스트

## 업그레이드 참고

- 마이그레이션이나 재색인은 필요하지 않습니다.
