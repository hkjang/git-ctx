# git-ctx v0.58.4

이번 릴리스는 이 플랫폼의 핵심 보장 — **답에 읽을 수 없는 저장소가 절대 섞이지 않는다** — 를 전 구간 시험으로 고정합니다. 기본 서비스 포트는 계속 `4747`이며 기존 API·MCP 호환성을 유지합니다.

## 배경

지금까지의 체인 시험은 모두 최초 관리자 자격으로 돌았고, 그 자격은 ACL 을 우회합니다. 즉 **핵심 보장 자체는 전 구간에서 한 번도 실행되지 않았습니다.** 신원 → 소스 principal → SQL 조건 → 도구 출력으로 이어지는 경로 어디가 끊겨도 시험은 통과했을 것입니다.

## 추가

- `TestAccessControlChainIntegration` — 저장소 두 개와 팀이 다른 개발자 두 명을 두고, 실제 MCP 키로 호출합니다.

```text
목록        각자 자기 팀 저장소만 나오고 상대 저장소는 나오지 않음
내용 검색   같은 심볼이 양쪽 저장소에 있어도 자기 것만 나옴
직접 지정   상대 저장소를 이름으로 지정하면 거부되고, 거부 문구가 존재를 확인해 주지 않음
키 제한     소유자가 읽을 수 있어도 키의 저장소 제한이 더 좁으면 그 제한이 이김
```

- ACL 조건을 무력화해 보고 이 시험이 실패하는 것을 확인했습니다.

## 검증

- FTS5 빌드·태그 없는 빌드 양쪽 전체 단위·통합·race 테스트
- 권한 체인 2.6초, `internal/app` 전체 39초 (체인 시험 5종 포함)
