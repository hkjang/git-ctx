# git-ctx v0.53.1

이번 릴리스는 저장소 지도에 **선언된 의존성 스택**을 더합니다. 기본 서비스 포트는 계속 `4747`이며 기존 API·MCP 호환성을 유지합니다.

## 주요 개선

- `get-repository-map` 응답에 해당 ref 가 직접 선언한 서드파티 의존성이 포함됩니다. 처음 여는 저장소에 코드를 쓸 때 어떤 HTTP 클라이언트·테스트 프레임워크를 써야 하는지는 그 저장소가 이미 쓰는 것이 정합니다. 지도를 읽는 순간 함께 알게 되므로 별도 호출이 필요 없습니다.
- **전이 의존성과 락파일 해석 결과는 제외합니다.** 방향을 잡는 데는 소음이고, 전체 목록은 `find-dependency-usage` 가 답합니다. 25개까지 보여 주고 그보다 많으면 남은 개수를 밝혀, 잘린 목록이 전체처럼 읽히지 않게 합니다.
- 인벤토리가 아직 없는 저장소는 스택 절 자체가 붙지 않습니다. 빈 목록을 "의존성 없음"으로 읽히게 하지 않기 위해서입니다.
- 도구 설명도 이에 맞춰 갱신해, 모르는 저장소에 코드를 쓰기 전에 지도를 먼저 읽도록 안내합니다.

## 감사 결과 (수정 없음)

- 비관리 도구 29종의 **빈 응답**을 점검했습니다. 모두 이유와 다음 행동을 함께 제시하거나 명시적 오류를 반환하고 있어, 근거 없이 비어 있는 응답은 없었습니다.

## 업그레이드 참고

- 마이그레이션이나 재색인은 필요하지 않습니다. 스택은 v0.52.x 에서 만든 인벤토리를 그대로 읽습니다.
- 인벤토리가 비어 있으면(재색인 전) 스택 절은 표시되지 않습니다.

## 오프라인 Docker 이미지

릴리스 자산은 아키텍처 접미사가 없는 다음 두 파일입니다.

- `git-ctx-v0.53.1.tar.gz`
- `git-ctx-v0.53.1.tar.gz.sha256`

```bash
sha256sum -c git-ctx-v0.53.1.tar.gz.sha256
gzip -dc git-ctx-v0.53.1.tar.gz | docker load
docker image inspect git-ctx:v0.53.1 --format '{{.Os}}/{{.Architecture}} {{.Config.User}}'
```

기대 결과는 `linux/amd64 10001`입니다. 아카이브에는 `git-ctx:v0.53.1`과 `git-ctx:0.53.1` 태그가 포함됩니다.
