# git-ctx v0.59.3

이번 릴리스는 **검색이 어느 경로로 답하는지 운영 화면에서 보이게** 합니다. 기본 서비스 포트는 계속 `4747`이며 기존 API·MCP 호환성을 유지합니다.

## 개선

- `get-platform-status` 는 전문 인덱스 사용 여부, 재순위 설정, 벡터 데이터베이스 상태를 보고합니다. 그런데 **운영자가 실제로 보는 콘솔에는 그 셋이 없었습니다.** 에이전트가 사람보다 플랫폼을 잘 아는 상태였습니다.
- `GET /api/v1/admin/health` 에 `search` 항목을 추가했습니다.
  - `fullTextIndex` — 색인 내용 검색이 전문 인덱스로 조회되는지, 훑기로 처리되는지
  - `reranker` — 꺼짐 / 켜짐(모델명) / 켜져 있으나 설정으로는 쓸 수 없음(이유)
  - `vectorDatabase` — 미설정 / 공급자·컬렉션·벡터 수 / 연결 불가(이유)
- 콘솔 **운영 상태** 카드가 이 값을 함께 보여주고, 재시도를 소진한 알림이 있으면 그 사실과 조치도 같은 자리에서 알립니다.

## 왜 중요한가

느려진 검색과 좁아진 답은 증상이 같습니다 — 결과가 이상하다는 느낌뿐입니다. 전문 인덱스가 없는 빌드인지, 재순위가 설정만 되어 있고 돌지 않는지, 벡터 데이터베이스가 끊겼는지는 원인이 서로 다르고 조치도 다릅니다. 화면에서 구분되지 않으면 아무도 고치지 않습니다.

## 검증

- 미설정 상태가 그대로 보고되는지, 설정만 되고 동작하지 않는 재순위가 `unusable` 로 보고되는지 시험
- 콘솔 렌더 스윕(관리자 화면 11종, JS 오류 0건) 재실행
- FTS5 빌드·태그 없는 빌드 양쪽 전체 단위·통합·race 테스트

## 업그레이드 참고

- 마이그레이션이나 재색인은 필요하지 않습니다.
