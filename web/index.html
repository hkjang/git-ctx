지원 도구

resolve-library-id
접근 가능한 라이브러리 ID 후보 검색
query-docs
버전별 문서와 코드 예제를 출처와 함께 검색
search-repositories
Library ID 없이 접근 가능한 Bitbucket·GitLab 저장소 검색
search-source
Bitbucket·GitLab Query API 기반 소스 검색
get-repository-map
저장소 언어·구조·진입점과 주요 설정 파일 조회
find-symbol / get-symbol-context
함수·메서드·클래스·인터페이스 검색과 정의 문맥 조회
trace-dependencies / compare-refs / get-change-impact
의존 관계 추적, branch·tag 비교와 변경 영향 분석

메타 데이터베이스

DSN 원문 없이 실제 연결과 migration 상태를 진단합니다.

PostgreSQL 연결 및 전환

복구 SQLite로 기동된 경우 PostgreSQL을 읽기 전용으로 시험한 뒤, 명시적 확인을 거쳐 스키마와 데이터를 이전합니다. DSN 원문은 암호화 저장되고 다시 표시되지 않습니다.

백업과 복구

백업은 Master Key로 암호화되며 복원하면 모든 활성 세션이 폐기됩니다.

검색 품질 벤치마크

정답 파일을 기준으로 Recall@K, MRR, nDCG@K 회귀를 검사합니다.
