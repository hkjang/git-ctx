Context7 호환 사내 문서 검색

Bitbucket과 GitLab 문서를 저장소 권한에 맞게 검색하고 AI 개발 도구에 연결합니다.

Keycloak SSO로 로그인하여 접근 가능한 문서를 검색하고 MCP 키를 관리하세요.

서버 상태 확인 중…

내 계정

Keycloak 신원, 플랫폼 역할과 소스 ACL Principal입니다.

내 MCP 연결

{
  "mcpServers": {
    "git-ctx": {
      "url": "/mcp",
      "headers": {
        "CONTEXT7_API_KEY": "${GIT_CTX_API_KEY}"
      }
    }
  }
}

키 원문은 환경변수에 저장하고 설정 파일에는 넣지 마세요.

지원 도구

resolve-library-id
접근 가능한 라이브러리 ID 후보 검색
query-docs
버전별 문서와 코드 예제를 출처와 함께 검색
search-repositories
Library ID 없이 접근 가능한 Bitbucket·GitLab 저장소 검색
search-source
Bitbucket·GitLab Query API 기반 소스 검색
search-code
저장소 이름과 코드 본문을 한 번에 검색
find-file / read-file
파일명·경로 패턴 검색과 파일 본문(줄 범위) 조회
list-directory / get-file-history
디렉터리 탐색과 파일 커밋 이력 조회
search-merge-requests
GitLab MR·Bitbucket PR 검색으로 변경의 배경과 결정 근거 확인
find-dependents
공유 코드·모듈·테이블을 사용하는 저장소를 전 범위에서 역추적
search-semantic
표현이 달라도 의미로 찾는 저장소 전 범위 검색
get-repository-map
저장소 언어·구조·진입점과 주요 설정 파일 조회
find-symbol / get-symbol-context
함수·메서드·클래스·인터페이스 검색과 정의 문맥 조회
trace-dependencies / compare-refs / get-change-impact
의존 관계 추적, branch·tag 비교와 변경 영향 분석
get-context-pack / find-runbook / export-context
업무 단위 복합 검색, 운영 절차 검색과 안전한 Markdown 내보내기
explain-search-result
검색 후보의 키워드 근거, 모델 버전과 원문 line 범위 설명

초기 설정 진행 상황

연결과 색인이 어디까지 준비되었는지 확인합니다.

관리자 설정

설정은 암호화되어 버전별 저장됩니다. Secret, PAT, Token은 재조회 시 마스킹됩니다.

Keycloak 역할·Claim 매핑 (ACL)

Keycloak 역할 이름을 플랫폼 역할로 연결합니다. 매핑이 없으면 관리자도 설정을 수정할 수 없습니다.

벡터 DB 상태와 마이그레이션

벡터 DB를 사용하지 않아도 검색은 동작합니다. 연동하면 키워드와 무관한 의미 검색 후보까지 찾고, 저장소가 커져도 성능이 유지됩니다.

연동 즉시 검증

저장된 설정으로 실제 원격 코드 검색을 실행해 결과 건수와 차단 사유를 확인합니다. 값을 바꿨다면 먼저 저장하세요.

고급 JSON 설정
변경 이력
설정 내보내기 · 가져오기

전체 설정을 JSON 한 파일로 옮깁니다. 비밀값은 포함되지 않으며, 가져오는 환경에 이미 있는 비밀값은 그대로 유지됩니다.

사용자 관리

Keycloak 사용자를 등록·조회·수정·삭제하고 역할을 관리합니다. 최고관리자는 모든 관리자 설정과 운영 기능을 사용할 수 있습니다.

플랫폼 역할

MCP 도구 운영

도구별 활성화·Timeout·캐시·응답 예산을 조정하고, 실제 호출 통계로 검증합니다.

도구별 지표와 설정

답하지 못한 질문

빈 응답으로 끝난 질문입니다. 색인되지 않은 저장소, 좁은 ACL, 오해를 부르는 도구 설명 중 하나가 원인입니다.

클라이언트 · 검색 경로 · 오류

호출 추이

연동 자가 점검

지금 이 계정의 권한으로 실제 검색 경로를 실행하고, 단계별 결과를 그대로 보여 줍니다.

세션(에이전트 대화)

답을 얻지 못한 채 끝난 대화를 위로 올립니다. 호출 하나만 보면 정상으로 보이지만 대화 전체로는 실패인 경우를 찾습니다.

호출 감사 로그

세션·클라이언트·질의·검색 경로까지 남긴 개별 호출 기록입니다.

소스와 색인 운영

저장소를 탐색·등록하고 색인 작업과 최신성을 관리합니다.

색인 진단

특정 사용자의 ACL Principal로 검색을 재현해 “왜 결과가 없는지”를 확인합니다. 코드 조각과 파일 경로는 표시하지 않습니다.

사례별 결과

보안

관리 Secret, 발급된 API 키와 색인 보안 이벤트입니다.

관리 비밀정보

설정 값에 secret://이름을 입력하면 실행 시 안전하게 해석됩니다. 원문은 생성·회전 요청 뒤 다시 표시되지 않습니다.

전체 API 키

색인 보안 이벤트

외부 알림 전달

Webhook, 사내 메신저 및 이메일 알림의 전달 상태입니다. 목적지와 인증정보는 표시하지 않습니다.

감사

설정 변경, 로그인과 키 운영 이력입니다.

최근 감사 로그

메타 데이터베이스

DSN 원문 없이 실제 연결과 migration 상태를 진단합니다.

PostgreSQL 연결 및 전환

복구 SQLite로 기동된 경우 PostgreSQL을 읽기 전용으로 시험한 뒤, 명시적 확인을 거쳐 스키마와 데이터를 이전합니다. DSN 원문은 암호화 저장되고 다시 표시되지 않습니다.

운영 상태

색인, 키와 관측성 상태 요약입니다.

백업과 복구

백업은 Master Key로 암호화되며 복원하면 모든 활성 세션이 폐기됩니다.
